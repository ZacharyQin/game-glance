# Game Glance 3.0.5

Coming from 3.0.x, update from Quick Access → Game Glance → Updates.

- **Sounds when you open and start a game.** Opening a game from Home plays Steam's own sound for going into a game's
  page, and Play plays Steam's game-start sound, as on the game page.
- **Space Required for Steam games.** A Steam game that isn't installed shows the space it needs, labelled "Space
  Required" in Steam's language, on Home (next to Played) and on the game page.
