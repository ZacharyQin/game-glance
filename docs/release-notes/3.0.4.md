# Game Glance 3.0.4

Stability for Spotlight Home. Coming from 3.0.x, update from Quick Access → Game Glance → Updates.

- **Home recovers from an error.** If Spotlight Home hits an error that used to break the Home screen (React error #130,
  reported on SteamOS), Steam's own Home now shows instead, and the screen keeps working. Turn Spotlight Home off in
  Quick Access as before if you want Steam's Home all the time.
- **A log for reports.** Game Glance writes `game-glance.log` to `~/homebrew/logs/Game Glance/`. It records each start-up
  and any recovered error. When you report a problem, attach that file.
